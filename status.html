DADOS DINÂMICOS — A IMPLEMENTAR

O que poderá vir do jogo

Depois que o servidor do Unity expuser uma API própria, o site poderá exibir estado/versão do servidor, changelog, distribuição pública das classes e catálogo vigente. Dados privados de jogadores, inventário e transações devem permanecer protegidos no backend.

Builds do Unity não aparecem automaticamente no site: cada versão precisa ser gerada, testada, empacotada e publicada. O site só libera o download quando o manifesto da versão for atualizado.
